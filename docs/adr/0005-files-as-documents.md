# 0005 — 笔记收进 File

**状态**：已接受（2026-08）

## 背景

笔记正文活在 SQLite `content`，导入文件活在磁盘。重命名、换格式、阅读视图无法共用。

## 决策

File 是唯一带正文的 Item 类型。新建笔记 = 创建一份默认 `md` 的库内文件；已有笔记迁移到磁盘。
`items.content` 只作文本搜索副本。切格式只改扩展名和 mime，不改字节。

## 备选

- **保留 type=note**：两条存储路径永远分叉，换格式做两次。
- **重建 CHECK 去掉 note**：要重建 `items` 表，收益只是约束更干净。

## 后果

- 搜索 `type:note` 解释为 markdown File，兼容已保存查询。
- schema 仍允许 `note`，数据层不再插入。
