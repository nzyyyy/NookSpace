# 0002 — 复制导入 + 库目录在 Application Support

**状态**：已接受（2025-08）

## 背景

用户把本地文件"加入"资料库时，不能破坏用户的原始文件；库必须自包含，
以便备份、迁移与未来的同步。

## 决策

- 导入 = **复制**：源文件从不动；副本存入 `~/Library/Application Support/com.nookspace.app/files/<uuid>/`。
- 元数据与索引存 SQLite（同目录 `nook.db`）。
- 重复导入按 `sourcePath + sha256`（存于 `meta`）去重：同源同哈希 → 跳过并提示"已在库中"。

## 备选

- **仅引用原路径**：零拷贝，但文件被移动/改名即失效，备份断裂 —— 拒绝。
- **移动源文件**：省空间但破坏性、不可逆 —— 拒绝。

## 后果

- 占用双倍磁盘空间（可接受；未来可加"导入后删除源文件"选项）。
- 用户不会在 Finder 里直接看到库内容，这是有意为之：应用拥有全部文件生命周期。
- Time Machine 默认备份 Application Support，备份无忧。
