# NookSpace 产品文档（最终形态）

> 本地优先的个人资料库：笔记、文件、链接统一管理，全部数据属于用户自己。
> 本文件描述产品的**最终形态**（v2.0 之后的目标全貌）；MVP 现状用状态标记区分。
> 领域词汇以 `CONTEXT.md` 为准；架构与接缝见 `docs/ARCHITECTURE.md`；关键决策见 `docs/adr/`。

## 1. 产品定位

**一句话**：一个安静、快速、完全本地的个人数字资料馆——把散落在 Finder、浏览器、
备忘录、微信文件里的东西，全部收进一个自己拥有、随时找得到的空间。

**目标用户**：单机个人用户（就是你自己）。重视隐私与数据所有权、讨厌订阅与账号、
希望用键盘快速完成一切、在意排版与细节的桌面使用者。

**产品原则**（所有功能的取舍标准）：

1. **本地优先**：默认不联网、无账号；任何网络能力都是用户显式开启的可选项。
2. **克制**：不堆功能；每个功能必须让"存入→找到"这个核心循环更短。
3. **键盘优先**：一切操作可键盘完成，鼠标只是补充。
4. **文件永不丢失**：软删除、自动保存、备份是默认行为，不是功能开关。
5. **排版与细节即品质**：typography、间距、一致性优先级高于装饰。

**最终形态的一句话**：*像 Things 一样安静，像 Raycast 一样快，像 Craft 一样会写字，
像 Spotlight 一样无处不在——但全部跑在你自己这台机器上。*

## 3. 功能全景与规格

### 3.1 内容管理（存入）

| 功能 | 最终规格 | 状态 |
|---|---|---|
| 笔记 | Markdown 为第一公民：编辑态纯文本、**阅读态渲染**（标题/列表/代码高亮/表格/Mermaid/公式） | ✅/⬜ |
| 自动保存 | 防抖 400ms，网络/崩溃不丢字；**版本历史**（笔记历史版本可回滚） | ✅/⬜ |
| 待办清单 | 笔记内 `- [ ]` 任务；**任务智能视图**按笔记聚合未完成任务；可设提醒 | ⬜ |
| 模板 | 笔记模板（日记、会议、读书等），一键套用 | ⬜ |
| 每日笔记 | Daily Note：当天新建/打开，自动日期标题 | ⬜ |
| 文件导入 | 复制进库、源文件不动、SHA-256 去重、文件夹→集合（均 ✅）；**批量重命名、文件新版本（同一文件再导入生成新版本）** | ✅/⬜ |
| 链接 | 手动标题+URL（✅）；**自动抓取标题/描述/缩略图（网络可选）、浏览器剪藏（分享扩展/快捷键）** | 🟡/⬜ |
| 附件 | 任意 Item 可挂任意 Item；笔记内**内嵌图片**（附件随文显示）；拖拽入库内 | 🟡/⬜ |
| 剪藏 | 全局快捷键捕获选中文本/剪贴板 → 存为新笔记（见 3.8） | ⬜ |

| 保存搜索 | 常用搜索存为保存视图 | ⬜ |
| 命令面板 | Cmd+K：模糊搜索 + 动作系统（**可扩展动作注册表**：任何功能可被面板调用） | ✅/⬜ |
| Spotlight | 系统 Spotlight 导入器：桌面任意处搜到库内容，回车跳转 NookSpace | ⬜ |

## 5. 技术演进方向（保持兼容）

> 目标：每一步都不推倒重来。MVP 的 schema、接缝、词汇表已为以下演进预留。

1. **Schema 迁移**（`rusqlite_migration` 追加版本）：
   - 002：集合 `parent_id` 启用、标签颜色列启用（列已存在，纯数据层）
   - 003：属性表（item 级 KV + 类型）、任务表、backlinks 表、saved_views 表、settings KV 表
   - 004：FTS 表（trigram → jieba 重建，原文列保证零成本重索引）
   - 005：embedding 表（向量列或 sqlite-vec 扩展）+ 索引任务队列表
2. **后台任务队列**：Rust 侧 tokio + SQLite 任务表（导入、缩略图、文本提取、embedding 统一走队列，UI 永不阻塞）
3. **AI 抽象**：`Provider` 接缝（本地 Ollama/MLX/Core ML + 可选远程），`docs/adr/` 记录，UI 层不感知模型差异
4. **预览升级**：qlmanage 外部窗口（现）→ 应用内 NSQuickLookPreviewPanel（插件或自研）→ 保持 `preview(item)` 深接口不变
5. **同步**：以"库快照 + 增量"为边界实现，与本地文件结构解耦；默认关闭
6. **前端**：TanStack Query 仅在查询复杂度真正上升后引入；虚拟化（@tanstack/react-virtual）在条目量大后加入

## 7. 非目标（明确不做）

- **多人实时协作**：不是 Notion/Google Docs，单用户工具。
- **网页版/云端主库**：主数据永远在本地；云只是可选镜像。
- **富文本 WYSIWYG 编辑器**：Markdown 是第一公民，所见即所得只会引入编辑器锁定。
- **移动端优先**：iOS 只是伴生（捕获 + 查看），桌面是主阵地。
- **平台泛化**：优先 macOS 打磨，Windows/Linux 不做优先级承诺。

## 8. 成功指标（最终形态）

- 打开到可用 <1s；冷启动无感知
- 10 万条目 / 1 万文件下，列表滚动与搜索无卡顿
- 100% 数据本地可读：关闭应用、拔网线，功能不受任何影响
- 备份 = 复制一个目录即可恢复
- 常用操作（新建/搜索/打开/移动）全部 ≤2 步且可纯键盘完成
